# V53 普通因果参照诊断

只读核查 V52 的 88 状态面板与两轮收据，没有重跑自然求值或修改 V52。优化轮仍不能分离因果策略损失；这主要暴露当前参照的计算组织不足，尚不能支持新算法需求或新颖性结论。

## 当前证据

- 88 状态覆盖 72 根：78 个车内、10 个平台；每格恰有两个根动作。五模式共 440 格的 `cache_hits` 全部为零。最优模式 86/88 格的所有根动作上界仍为截断上限。
- 面板菜单树共出现 8152 个 ride、3927 个平台；其中 5852 个 ride 只有吸收终点，3647 个仍含两段以上；全部路径含 5629 个非出口中间车段。按日期与 cid 路径去重，终点专用路径有 415 条。以上是菜单树出现次数，不能作为独立决策样本数。
- 3927 个平台中，3121 个包含所属车次已不在该平台任何剩余路径中的观察车辆。共同观察合同共出现 35967 个 cid，其中 27308 个属于这些独立无关车次；每平台平均观察 cid 从 9.16 个降至 2.20 个。按车次而非 cid 判断相关性，同车信息车辆仍保留。
- `mass_terminal` 仅压缩当前末段的到达积分。它仍为此前每次发车／到达生成历史；平台递推先深入正事件分支，再结算无事件链，局部概率排序没有解决全树预算分配。

## 优先修复

1. **整条无选择尾程积分。** 当当前位置至首个吸收终点没有其他出口时，用根 P0 条件链的后验转移矩阵推进存活质量；每个经过的发车／到达保留原取消、时间合法性和截断掩码。终点结果为 `H*(1−存活质量)+Σ 存活质量×到达时刻`。中间观察之后不再有决策，逐历史求和可按全期望公式合并。适用于全部五模式，不改变工作评分规则；优先于一般非终点跳段。
2. **对无关观察精确求和。** 若某观察车次不出现在当前及任何后续可行路线中，则其独立随机过程不改变成本、合法动作或原 cheap 评分；其所有观察分支的和为 1。计算中消去这些分支，执行器和可获得信息合同保持不变。任何仍有后续相关 cid 的同车观察不能删除。
3. **用剩余菜单相关历史作缓存键。** 先去掉已不相关车次的记录，保留同车完整证据。进一步压缩无选择前缀需要证明最后精确槽位屏蔽更早记录，并检查后续不会重新查询该边界前的槽位；不能未经核查就删掉观察。原 W 的消息重选还依赖最大已完成槽位，需要保留。完整键零命中证明当前没有共享收益，不保证投影后必然大量命中。
4. **再调整根额度。** 现实现两个根动作按固定顺序各获累计一半 CPU／状态额度；只有前一动作未用完时才单向回流。固定 cheap 模式也为未选根动作付出约半份潜在额度。选中动作优先、共享剩余额度或按根区间贡献调度均可保持值界有效，但必须保留所有动作的未解范围，完整计费，不把这种普通调度称为新方法。若以后重用不完整缓存，还须允许继续细化，不能把首次预算停止的宽界冻结永久复用。

## 下一步验证

先以小链独立枚举核对整段积分（含取消、跨段截断），以同车信息正例／独立无关观察反例核对边缘化，以相同相关后验但不同无关历史核对缓存合并。然后只在原 88 状态、五模式、2000 状态／2 秒 CPU 下与 V52 两版本配对，保存全部正负及未解结果，报告逐格界宽、完成数、认证数、缓存命中和总费用。两版本区间须相交、严格认证不得冲突；局部条件值不外推为根期望遗憾。

本诊断统计来自 `reconstruction_v52/panel.json.gz`、`natural_optimized/` 及原本地 dated graph，未读取未来标签，也未拉取服务器数据。上述改动是普通参照补强；只有有用值界出现后，才能继续判断剩余决策缺口和独立方法贡献。
