# Calibration and continuation interface

The current predictors can supply a **local diagnostic probability** after the same rider-known incoming arrival: `law = model.predict(incoming_source, outgoing_source, observed_arrival)`. For a still-unknown different-trip target, compute `(1-law.cancel_probability) * (law.cdf(min(deadline, ready+720))-law.cdf(ready))`, with zero probability when `ready >= deadline`. Inputs and laws use service-day **seconds**. The existing `ContinuationRouter._boarding_support` uses the legacy minute grid and a 12-unit window ([source](../../src/continuation_router.py#L135)); seconds cannot be passed through that interface unchanged. Known target events and prior wait/attempt feedback must retain the existing belief's conditioning rather than be overwritten by an earlier route marginal.

The date-block envelope adjusts interval endpoints only. It is not a CDF or probability recalibration. Shrinkage defines a learned local conditional law; its pairwise conditionals have not been constructed as a consistent full-network joint law. The heavy-tail candidate defines a local two-role joint model, not the ordered departure/arrival and partial-service chain needed for a whole itinerary.

The branch identity is $E_P[V\mid H]=p_P E_P[V\mid C,H]+(1-p_P)E_P[V\mid C^c,H]$, where $C$ is catching the first vehicle and every term uses the same posterior joint law $P$. Replacing only `p_fail` in [`ContinuationRouter._score_action`](../../src/continuation_router.py#L280) while preserving its old sampled conditional losses does not establish the value under the newly fitted law. Catching and missing can select different delay, arrival, recovery and information histories. An explicit common-world importance reweighting could define another law, but it would need consistent treatment across actions and histories; the scalar calibrator does not supply it. The seconds-based full-menu [`CausalPlanningRouter`](../../src/causal_planning_router.py#L207) instead values complete scenarios from `trip_belief.sample`; changing a scalar probability alone does not change those scenario values.

An explicit joint candidate is now implemented through the existing `event_belief` interface in [`JointDayBelief`](../../src/joint_day_belief.py). Its `copy`, observation/forecast/wait updates, `event_distribution`, `mean_events` and `sample` use one 13-component posterior mixture of ordered `EvolvingTripBelief` laws. Every private world draws one common day offset, with route means shifted by that offset and the original increments/service model unchanged. Revised-trip full likelihoods update the same day posterior used for subsequent marginals and samples. [`IndependentDayMixtureBelief`](../../src/independent_day_mixture_belief.py) supplies the matching-initial-marginal control with persistent independent per-trip offsets. These are additional parametric joint candidates; they do not turn the earlier empirical local CDFs into a full-network model by relabeling them.

Existing production beliefs and routers were not changed. The new candidates enter separate matched mechanism runs. Mixture calculations are exact for the current given grids; off-grid observations still augment the underlying clock support, so inference is an adaptive approximation to a global continuous-clock posterior. Shared day uncertainty invalidates the unmodified independent-trip relevance argument because observing one trip can change another trip's law. A coherent candidate and a tested joint interface do not establish calibrated probabilities or journey-policy improvement; those remain empirical questions in the separate frozen results.

The completed [joint mechanism record](joint_day_v2_RESULTS.md) contains 36 logical-time and 18 charged rows on the same six development journeys. Shared rollout improves on the matching-marginal per-trip control, but its 23.67 s logical advantage over Gaussian becomes a 74.17 s deficit after measured computation. The interface is executable and internally consistent on its current grids; the fixed experiment does not establish a practical advantage over the inexpensive baseline.
