# V27：便宜等待规则解释了六根 DP 收益

**这组状态需要更好的等待续策略，但完整子集 DP 没有显示独立价值。** 已新增纯计划排序、条件单目标等待、单目标与旧首机会等待估值的无参组合。固定 V26 六根、两个模型、菜单与执行合同，复用全部 **1536 个原世界**；新增世界为零，旧首机会结果逐世界复现，新增 **10 项测试通过**。

## 配对结果

单位为平均截断旅行损失秒。实际六根包括原五负一正，均保留。

| 面板 | 计划排序 | 单目标等待 | 组合等待 | V26 DP |
|---|---:|---:|---:|---:|
| 实际六根，两模型分别回放 | 916.50 | 916.50 | 916.50 | 916.50 |
| 修正模型原 768 世界 | 1390.55 | **1246.56** | **1246.56** | **1246.56** |
| 原模型原 768 世界 | 1549.06 | 1506.67 | 1506.67 | 1507.86 |

实际六根的新三臂与 DP 首乘、尾程和损失一致，全部到达。修正模型的单目标／组合与 DP 在 **768 个世界逐个动作与损失相同**，均全部到达。纯计划排序在模型中仍差 143.98 秒，说明适应当前公开机会仍有价值，不能只保留“固定等计划最好车辆”。

原模型中单目标／组合与 DP 有 5 个首乘分歧，其中 3 个损失相同、2 个单目标更好；单目标平均少损失 1.20 秒，配对 MC 标准误 0.94 秒。单目标／组合／DP 各到达 757/768，纯计划排序为 748/768。分歧和失败全部保留，不据此宣称单目标普遍支配 DP。

## 精确代理与计费

从同一个名义登乘成本出发，精确积分得到单目标相对最优 DP 的初始代理期望差：修正模型平均 **0.000040 秒**，原模型 **0.189 秒**。全部保留支持状态中的最大差分别为 **0.000052 秒、0.541 秒**。组合没有进一步缩小这些差距。这是固定有限代理表的差异，不是实际旅行遗憾证书。

修正模型六根的单目标后缀准备共 0.000543 秒，约 **0.000090 秒/根**；V26 的 DP 增量编译为 0.080 秒/根。计入本轮模型、名义评分准备与在线选择，单目标为 0.385 秒/根；V26 DP 历史账本为 0.461 秒/根。模型及评分仍是主要费用，两轮计时不是新做的同时机器基准。纯计划排序不编译模型，六根策略准备与在线调用合计约 0.00015 秒。

## 决定与下一步

收束这六根上的完整 DP 增量主张，将**条件单目标等待冻结为主要强基线**，保留首机会、旧一步和组合控制。当前卡点是收益可由便宜方法取得，继续优化子集 DP 或追求这 40 微秒差距不能解决 G2；完整 G2 仍未通过。

下一阶段在 V25 原有全部冻结菜单检验单目标规则的迁移：48 个出发根为主、25 个条件换乘根为次，包含 18 车菜单；继续保留缺测与正负结果。先验证简化后规则的适用边界，再决定是否存在值得研究的新方法缺口。
