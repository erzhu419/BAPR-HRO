# V27：多步等待的便宜控制

保持 V26 六个开发根、两个冻结 20 秒模型、完整五车菜单及原 1,536 个随机世界。公共观察、发布、MCT、截止时刻和下游首机会补救一致；不增加精确登乘评分。新增计划排序、单目标及其与旧等待代理的无参组合，用于判断多步等待的收益是否需要子集 DP。

## 计划排序等待

每个候选按冻结菜单中的计划终点到达时刻、连接 ID 排序。一次公开机会发生时，从当前合法可乘车与尚未观察到的候选中选排名最前者：若它当前可乘就上车，否则等待。只移除已经公开的发车或取消，不因为计划发车时刻已过就认定车辆消失。当前同秒公开的车辆在拒乘后全部移除。

该规则只用公开时刻表和当前信息，因果可执行；每次查询扫描候选，成本为 $O(K)$。它可能等待一辆进站前已走但没有被观察到的车，直至截止，因此只是极简机制对照，不能独自充当最强名义规划基线。

## 单目标等待改进

令观察开始为 $e$，当前公开时刻为 $t$，截止为 $H$。对尚未出现的候选 $i$，沿用同一个冻结根发车律 $p_i(u)$、取消质量 $c_i$ 和 V26 的 `clock_nominal` 登乘成本 $b_i(u)$。局部未出现的条件概率分母和单目标等待成本为

\[
 q_i(t)=c_i+\sum_{u<e}p_i(u)+\sum_{u>t}p_i(u),\qquad
 J_i(t)=H-\frac{\sum_{t<u<H}p_i(u)[H-b_i(u)]}{q_i(t)}.
\]

分母保留进站前已走、取消及截止以后发车的概率；这些情形没有可兑现的截止节省。分子只包含严格晚于当前时刻且早于截止的合法机会。当前发生查询时旅客已就绪，因此不再需要额外截掉就绪前的分子项。

$J_i$ 是“从现在起只等候 $i$，有合法机会便按共同续程执行，否则在截止损失 $H$”的冻结代理期望。取所有有效 $J_i$ 的最小值，与当前合法车辆的最小 $b_i(t)$ 比较，并列时登乘。每次后续公开机会重新比较，不把上一次最优 $i$ 变成不可撤销承诺。所有当前公开车辆都从下一等待集合移除，不能把同秒被拒绝的另一辆车留作未来机会。

$q_i=0$ 表示该模型不支持此未出现历史，应记录而不将它解释为已观察到取消；该候选不产生有效的等待比较项。实际网格外时刻仍使用当前真实秒钟的 $b_i(t)$，未来求和严格取 $u>t$，不把未来概率移到当前。

每车预存发车质量及截止节省的后缀和，每车查询只需两次后缀定位。因此准备这些后缀在已有分数之外为 $O(\sum_i N_i)$，等待查询为 $O(K\log T)$，存储为 $O(\sum_i N_i)$。原模型推断、完整菜单和登乘分数的准备仍需计费；当前网格外车辆通过原接口计算登乘分数的费用也计入在线调用，不能把整个决策称为后缀查表。

## 两种便宜等待代理的组合

在读取 V27 结果前，另固定一个直接组合对照。设 $W_{\rm first}(t,S)$ 是 V25 的“下一首机会便上车”代理，组合等待值为

\[
 W_{\rm combined}(t,S)=\min\left\{W_{\rm first}(t,S),\ \min_{i\in S:q_i(t)>0}J_i(t)\right\}.
\]

它将该值与当前最佳合法登乘成本比较，下一次公开机会重新计算；没有额外阈值，也不锁定所选未来目标。两项分别保留互补备选的作用和跳过较差中间机会的作用。该组合仍是基于两类固定续策略的局部改进，不等于完整拒乘树的最优值。它的费用包含原首机会代理的计算，不能沿用单目标查询的 $O(K\log T)$ 作为组合总成本。

## 比较边界

各控制均不读取实际未来。单目标规则会利用漏车与取消概率，避免纯计划排序完全忽略这些风险，但它也不一定优于 V25 的“下一首机会”代理。例如两个独立候选各以一半概率可来、登乘成本均为 30、否则成本 100：只等任意一辆的期望为 65，而搭首个可来车辆的期望为 47.5。因此保留原滚动一步控制和直接组合，一起判断便宜方法的质量与费用；不预先宣称某条规则支配所有旧基线。

冻结代理下的完整子集 DP 包含这些可行策略，其最优值不高于它们；该关系不推出实际旅行损失逐世界不劣。原世界复用只减少配对噪声，不形成新的独立日期确认。若便宜控制已解释六根收益，应收束这些状态上的 DP 增量主张；若仍有差距，再判断差距是否足以承担新增计算。两种结果均不单独建立 OR 方法新颖性或通过完整 G2。
