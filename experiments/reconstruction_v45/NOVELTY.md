# V45：首次下车状态压缩的先例与立项范围

本轮以 V44 matched128 为强对照，固定模型、菜单与信息。待证明的具体结构是：在同一根上下文内，首次下车前的实际 π 行为及所到平台的 κ_updated 值，是否只依赖当前本车槽位、已观察时钟和必要的消息选择状态。若成立，可按这些状态共享 128 世界的前缀求值，并用吸收链递推直接积分 κ 的总体期望。**状态压缩、条件积分和吸收链递推本身都是已有方法；独立贡献不能预先成立。**

## 最接近的原始先例

| 本轮需要的原理 | 已有结果及区别 |
|---|---|
| 用较小状态保持后续策略价值 | [Givan、Dean、Greig，2003](https://cs.brown.edu/people/tdean/publications/archive/GivanetalAIJ-03.pdf)建立 MDP 等价与模型压缩。这里需要的是固定策略、固定根上下文下的条件等价；不能由物理链 Markov 性单独推出工作信念和策略也可压缩 |
| 对结构化策略求值、计算误差界 | [Koller–Parr，2000](https://arxiv.org/pdf/1301.3869)使用结构化策略及变量消元，并计算分解值函数的误差界。这里的单消息重选、同车整链和根物理法则／工作信念分离，需要项目内的明确证明，但不创造新的消元原则 |
| 保留部分采样，解析消去可积变量 | [Doucet 等，UAI 2000](https://abbeel.berkeley.edu/cs287-fa11/optreadings/DoucetdeFreitasMurphyRussell_RaoBlackwellizedParticleFilters.pdf)及 [Murray 等，AISTATS 2018](https://proceedings.mlr.press/v84/murray18a/murray18a.pdf)已系统利用条件可积结构。首次下车分布的精确传播属于这一类；仅对同一个 κ 目标消除前缀抽样误差，不能据此消除 κ 对完整 π 的替代误差 |
| 公交等待、登乘、下车的动态规划 | [Liu 等，2018](https://arxiv.org/html/1808.04360v2)包含反复等待、目标车等待启发式、支配与剩余质量剪枝；[Rambha、Boyles、Waller，2016](https://pubsonline.informs.org/doi/10.1287/trsc.2015.0613)用到站时刻及实时车辆信息建立有限时域 MDP 并缩减状态。因此“多步适应＋有限状态 DP”并非新的问题原理 |
| 截断 rollout 的尾值误差传播 | [Bertsekas，2021，Proposition 2](https://web.mit.edu/dimitrib/OldFiles/www/Multiagent_Sinica_2020.pdf)给出截断 rollout 的终值误差及策略性能界；[Scherrer，2013，§4／Appendix E](https://www.jmlr.org/papers/volume14/scherrer13a/scherrer13a.pdf)区分策略残差与最优性残差。新增任务必须是便宜构造本项目可用的误差界，而非重写一般误差传播公式 |
| 首次策略分歧前共用轨迹 | [Schulman 等，2015，Appendix A](https://arxiv.org/pdf/1502.05477)已用策略耦合证明性能界。这里的“剩余时间 × 分歧概率”是通用路径耦合界；真正难点是无需完整求值就算出有效分歧概率及共同登乘后的标记误差 |
| 放松未来信息得到价值界 | [Brown–Smith–Sun，2010](https://pubsonline.informs.org/doi/10.1287/opre.1090.0796)建立信息松弛与对偶界。利用未来真实车次作乐观界，或用罚项修正它，不能单独作为本项目新理论 |

## 选择该结构的理由

Markov128 保留原 128 个世界，目标是逐世界 κ 值和动作保持一致，只减少重复条件化、历史重建和前缀评分。证明必须同时覆盖：根物理分布的未来转移、工作信念选择的有效消息、停止动作以及吸收平台的 κ 值。历史中仍可能再次被选择的预测不能仅因当前未使用就删除；本车若在尾菜单中复现，也不能仅凭当前到站时钟断言所有过去查询无关。

Exact absorbing 使用同一可证明状态，直接传播首个下车平台／时钟与直接终值的概率。它针对 κ 的总体期望，因而无需保持与有限 128 世界均值数值相等。它也不等于完整 π 的价值。复杂度优势应明确落在“前缀历史数量或样本数依赖变为可达有限状态与转移数量依赖”；固定 N=128、支持状态较多时不保证更快，全部费用仍须配对实测。

另已推导出按最佳可见评分分解的加权子集变换，可把局部求值 O(T·3ᴷ) 改写为 O(T·K²·2ᴷ)。但 [Björklund 等，2007](https://arxiv.org/pdf/cs/0611101)已给出同量级的快速子集卷积；本面板 K 最大为 5、绝大多数为 4，渐近计数也不占优。这条路线本轮不作为独立贡献方向。

## 动作差值界的边界

可优先检查真正终端车程子类：平台根属于独立物理车，登乘后无进一步决策。若能分别构造未见车的 WAIT 标记、观察其发车后实际 π 的可见评分、根物理法则下的真实终点条件均值，则局部有限 DP 可以精确评价实际 π，允许观察触发预测重选；与 κ 的差值可直接计算。非终端尾菜单中，其他车辆的已见时刻可能改变后续换乘评分，这个子类证明不能外推。

实际菜单中存在该子类的部分覆盖，本轮暂缓三标记终端求解器，避免把首次下车结构检验扩为另一套完整策略求值工作。精确吸收递推只把各首次平台的真实尾值置于物理范围 `[到达时刻,H]`，再按精确吸收概率加权，得到完整 π 总体动作差值及 Δπ−Δκ 的粗界。它是标准范围／全期望界。强制 ALIGHT 立即进入未认证根平台，已占据整个 `[根时刻,H]` 范围，故该差值界在本轮必含零；这条粗界路线不能提供有效动作认证，不建设全信息树求解器来替代缺失的便宜结构。

首次下车压缩若有效，先认定为有证明范围的计算改进；若仍只是已知消元原则的实现，没有独立结构结果或新的重要洞见，则方法独立性仍未建立。所有正负案例保留，V44 的净计算结果不被重新包装为本轮新颖性。
