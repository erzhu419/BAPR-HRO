# 混合一次换乘尾部：方法定位与对照

本轮固定根物理法则 P0、观察后工作信念 W 与原基策略 π，目标是两首动作后完整 π 的总体价值差。三标记终段求值器、自然菜单精确参照首先是纠正评价对象的必要工作；它们不自动构成独立新方法。V45 的规范历史构造及已有计算收益保留。

## 已重新查阅的直接先例

| 本轮构造 | 原始先例及本轮需要解释的区别 |
|---|---|
| 只保留会影响未来的观察，合并其余历史 | [Givan、Dean、Greig（2003），§3.3、Theorem 7](https://cs.brown.edu/people/tdean/publications/archive/GivanetalAIJ-03.pdf)给出状态等价与商模型保持结果。这里必须由菜单构造代表，分别证明 P0 的条件物理分布、W 的实际选择、未来菜单和终值保持；引用一般定理不能代替这个证明。 |
| 固定策略的事件树、相关状态缓存及变量消元 | [Dechter（1996）](https://ics.uci.edu/~dechter/publications/bucket-elimination.pdf)统一概率推断、条件化与期望效用消元；[1999 完整版](https://www.sciencedirect.com/science/article/pii/S0004370299000594)的复杂度依赖诱导宽度。固定 π 可视为公开历史到动作的确定性因子，这是本项目的归约判断。图中必须计入候选评分和观察选择因子；一条跨候选引用不代表树宽为一。 |
| 保留未展开概率质量的范围，优先展开最能缩界的分支 | [Horvitz、Suermondt、Cooper（1989）](https://erichorvitz.com/ftp/boundedc.pdf)的 bounded conditioning 已把问题分成互斥子问题，逐步收紧概率界，并按预期缩界贡献安排求解。将此思想用于有界旅行成本得到期望区间属于直接扩展；“区间排零就停”本身不能作为新原理。 |
| 公交等待、登乘及换乘子集 DP | [Liu、Blandin、Samaranayake（2018/2019），§3–4](https://arxiv.org/html/1808.04360v2)已构造等待／登乘／换乘 DP、支配规则与单目标等待启发式。它的准时到达目标和信息模型与这里不同，不能声称已完整解决具名车次链及预测重选；也不能把多加一层换乘等同于新方法。 |
| 逐步采样并在差值显著时停 | [Howard 等（2021），§4.1、Theorem 4](https://arxiv.org/pdf/1810.08240)给出有界观察的时间一致置信序列。配对差值可作为有界样本使用；随机停止仍须保留覆盖保证，普通固定样本区间不可反复查看到排零为止。 |

WAIT 评分、观测发车后的 BOARD 评分与 P0 下实际终值 M 必须分别计算。这修复“策略用什么决定”与“已决定后实际发生什么”的混淆，尚不足以单独主张新理论。真实值不能回灌原 π 的评分；共享车次的旧精确时刻也不能因 seen mask 相同而删除。

## 能够成立的具体贡献假设

实时乘车策略同时面对同车事件相关性和预测重选。值得检验的是：在自然出现的一次换乘菜单中，能否从输入构造一个严格小于全历史的共享观察接口，同时保持完整固定策略价值，或在没有完整求解两臂之前给出有用的动作差值界。应用结构的构造和证明可能有数学价值；只有其可解范围、费用性质或重要应用洞见区别于最强普通结构化求值时，才支持进一步的算法论文主张。

确定性参照应与普通事件 DP／变量消元在相同模型、相同 π、相同精确或区间目标下比较。普通方法同样可以使用合法的相关状态缓存、终段标记和输入结构；不能以未经优化的全路径枚举制造优势。应分别报告自然输入的活跃接口大小、可达状态、转移／事件子集数及评分编译成本，不能只给形式上的小接口维数。

V45 Markov128 与完整 rollout128 保留为现有质量—费用参照，二者的点估计不充当总体真值。若另测统计认证，固定样本或序贯配对方法须评价同一完整 π 的差值，预先声明置信目标和样本上限；确定性界与概率置信界分列。共同预处理、冷启动、构界、失败及回退费用均归入实际调用成本。

## 本轮继续与停止判断

先完成真实相关混合状态的可信参照及小链独立枚举。只有输入构造的压缩确实省掉相关历史，或区间在未完成两臂精确求值前排除动作，才进入全关键状态费用比较。只得到较窄但始终含零的界、需要先精确求解才能构界、或普通 DP 已以相同成本实现全部效果，均不能支持该新方法假设。若精确自然参照成本高，保留其离线诊断用途，不把费用隐藏为在线免费预处理。

未证实的阶段不能按日历或版本号强行展开。当前文献核查没有证明独立方法贡献成立，也没有证明这种应用结构不可能形成贡献；它规定了下一实验必须实际区分的对象。
