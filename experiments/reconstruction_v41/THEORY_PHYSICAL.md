# V41 物理条件链

版本为 `V41_exact_integer_anchor_finite_chain_v2`。保留 V34 的路线参数、行车/停站/间隔增量、服务状态转移和原有限格点。从原 prior 开始按公开硬观测顺序重放：只有新整数秒钟不在当前支持中，才加入锚点并复用 `EvolvingTripBelief` 的锚点构造，重建有限有序链；在支持内的观测只条件化原基底。所有方法使用这一新版本；V40 投影模型结果不改写。

**v1 已废弃。** v1 首次查询会把当时全部已知时刻用于加格点，导致同一公开历史因较早或较晚调用评分而产生不同边际。该缺陷会改变概率，不只是缓存身份差异。v2 的首次 lazy 查询也重放完整观测序列；后续仅处理新增前缀，clone 保留基底、已处理观测及插入锚点。因此网格由有序公开证据确定，与评分调用时序无关；v1 实验仅保留为 provisional。

给定已固定的物理基底，每条车次的联合质量为

\[
 p(x_{0:L}\mid H)\propto \pi(x_0)\prod_{j<L}K_j(x_j,x_{j+1})
 \prod_j e_j(x_j;H).
\]

其中原核在 `t[j+1] < t[j]` 时严格为零；硬观测的 emission 只允许该精确时刻且车辆运行，未见窗口只排除窗口内运行状态。预测使用既定 V35 参数及 V36 单消息选择规则。前向后向评分与 FFBS 抽样消费同一个 `_ChainLaw`，故已知时刻为内部点质量，未来发车不可能早于已知到站。`CheckingWorld` 只检查锚点相等，绝不覆盖抽样时刻；没有 clamp、重抽或丢弃不兼容世界。

抽样前为全部相关车次建立物理基底。`clone()` 共享不可变基底；后续抽出的 own 事件已在该支持上，只重新施加观测/预测 likelihood，不再细化网格。在消息选择不变时，这就是同一有限链的精确条件化。预测重选沿用既定规则，不声称它来自一个已证明的联合消息生成模型。真实新 off-grid 观测引起的网格细化是显式模型近似更新，不能称作旧 V40 离散先验的严格 Bayes 条件化。

v2 中同一有序公开历史确定同一数值物理基底。`basis_context()` 额外返回进程内 `(trip, id(base))`，供同世界共享对象的直接比较；clone 保持其身份。独立重建可以拥有不同对象身份，但支持和概率一致。规划器节点、转移及动作缓存保守地区分对象，禁用旧 `prior_future` 原支持捷径。跨状态原始公开记录仍全部保留。

定向验证包含小链完整枚举与边际/采样比较、精确 off-grid 锚点与非倒序、同基底后续条件核、未见窗口及取消质量、消息重选、评分/抽样共用条件核、矛盾证据显式拒绝、早/晚评分查询和快照恢复的支持/边际/核一致，以及样本 clone 后不增支持。此修复证明内部物理支持闭合，不证明现实校准或方法新颖性。
