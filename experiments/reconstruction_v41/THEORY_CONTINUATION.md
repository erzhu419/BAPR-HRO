# V41：策略续程参照、普通会合与发布合同

每个固定公开状态、菜单和物理基底下，先生成每辆物理车的一条共同路径。两臂分别强制当前 ALIGHT／CONTINUE，随后执行同一指定便宜策略，包括平台观察、拒绝首车、后续车内下车及原单消息重选。条件世界没有未来档案帧；不把实际后续消息或终点塞进条件估值。因此完整模拟给出的是“冻结已收消息、允许新自身／本地观察”下的策略值参照，非全未来消息树的最优值。

两臂共享每个车次的整条样本链。同车在不同分支出现时读取相同物理事件；不同车次仍按原独立结构生成。样本数固定为 16 或 128，16 使用 128 世界 bank 的前缀，128 个生成世界均计费。这里不存在 CPU 驱动的选择性样本停止。有限 bank 的缺测界沿用 `[0, deadline−clock]`；只有一个完整配对时，标准误和正态区间为不可估计，不填零。

## 普通会合对照的等价性

`MeetingExecutor` 的表只存活于同一个配对世界。只在车内行程／站台访问入口比较完整剩余菜单、入口钟、已处理事件界限、全部有序硬证据、全部原始预测及公告、消息状态、物理基底身份。基策略、模型、截止和共同世界由同一评估器固定。这些量相等时，下一公开观察由同一个世界确定，条件更新及当前策略也相同；对后续事件递推，全部动作、状态及终值相同。因此第二臂可复用第一臂已完成的后缀，并复制其轨迹和决策计数。

这里没有通过两个不同世界的偶然相同当前动作推断未来会合；未选旧预测及基底身份均保留。键检查、存表和复制均计入 CPU。该实现检测的是上述入口的严格会合，不声称找到最早会合或所有可能的等价类。是否净省时由完整／会合两实现的同样本配对测量决定。

这种消去共同未来的原则已有直接先例。[Zahavy 等，UAI 2020](https://proceedings.mlr.press/v124/zahavy20a/zahavy20a.pdf)，§2 后段（PDF 第6页）、§4（第9页），研究不同首动作后沿共同策略运行并累计到会合的差值。本项目是有限截止、共同物理世界及含历史的执行状态，不直接移用该文平均奖励／遍历链的复杂度保证；普通会合本身不作为新颖性主张。

## 发布与计算的关系

实际发布器将 fallback 同步写入独立消费通道，工作线程只能通过提交接口提议替换；接收时检查行动身份、合法性、期限和是否已消费。调用方可在后台结束前取走已发布指令。迟到建议拒绝，后台费用仍记录；`finish()` 仅用于最终记账。真实线程的及时、晚到、零窗案例保留原始回执。

自然档案没有公共门开／关窗口，主旅行实验采用既定理想公开事件合同：相同逻辑时刻完成计算及取指令，实际 CPU 另计。接口一致不等于真实硬截止可行。不能将档案未来发车钟当成决策时已知期限，也不能在原理想发车时刻后随意加耗时、把所有基线判为错车。

行动过期与规划竞争也已有研究，例如 [Shperberg 等，AAAI 2019](https://cdn.aaai.org/ojs/4077/4077-13-7134-1-10-20190704.pdf)，PDF 第1–2页的问题定义。此处补齐执行合同和外部可用动作，不将接口修复视为新控制原理。

## 立项边界

物理支持闭合、浅层等待估值及标准会合分别回答正确性、便宜基线强度和计算空间。一个仍有收益的完整 rollout 不会自动成为新方法。进一步差异依赖范围需要可从输入构造、能证明未来策略不再受被删变量影响，并比标准上下文缓存／会合减少工作；仅有当前 key 相同不足。未来消息方向则需要支持消息发布时间与条件内容的模型。没有这些前提时，本轮不启动更大求解器或独立日期确认，以明确理由结束立项判断。

一个直接反例排除了“仅保留两菜单的对称差”这种构造。假设后续本地观察揭示共同候选的成本 x，两分支分别还有成本 10 与 20 的私有后备，固定便宜策略均在观察后选较低者。两臂值为 `min(x,10)` 和 `min(x,20)`；共同变量 x=5 时差为 0，x=15 时差为 −5。即使 x 属于菜单交集，它仍通过后续策略选择改变差值，不能在构造差异范围时直接消掉。若只要求当前选择相同，未选旧预测后续重选的已有反例同样排除永久会合。正确但保守的依赖闭包退回所有可能影响后续选择的共同变量；现阶段没有证明其比已知相关信息筛除更小的构造性范围或新的复杂度分离。
