# V55 输入结构：终端子平台可分，关键根整体仍耦合

固定 V52/V53 的全部 88 状态、72 根，只读 V41 模型映射、V50 菜单和根公开历史，未计算自然策略值。[可复现脚本](structure.py)输出[逐根逐平台数据](structure.json)。平台按每个查询内的菜单结构去重；这里统计结构可达菜单，不是正概率信念状态或策略访问频率。

1486 个物理平台中，**1199 个（80.69%）是纯终端子平台**，其候选来自不同车次，且合同中不存在相关车次的额外非动作本地观察。候选数分布为 1/2/3/4/5/6 辆对应 579/408/108/49/45/10 个。它们覆盖全部 88 个状态，具备接入末平台精确等待 DP 的输入条件；不能因此把原 combined 策略替换成首机会策略。

七个关键根的立即下车平台全部仍是混合续程，不能直接接终端 DP。两动作共享车次不是可直接消去的相同值，也没有显现一两个车次的小分隔集。

原评分语法含 **6208 个首目的地 occurrence，全部未被当前公告标为不可用**；其中 256 个在目的地后仍有路径。若首目的地吸收屏障的支配证明成立，可将根评分读取的车次成员总数 **2183→2008（−8.02%）**，66/88 查询缩减。这个条件截断没有增加纯终端平台数（原评分纯终端数同样为1199），主要减少混合平台的共享评分尾。完整同车 law、原预测及原 ranks 应保留，不能把目的地后的软观测从车次后验删除。

因此，真实输入支持“语义支配删去冗余评分尾＋精确终端子平台”作为普通因果参照分解的候选；不支持把整根当独立候选块，也不证明小分隔集算法或新方法贡献成立。其实际宽度—耗时收益须在完整面板上验证。
