# 同车两端可赶乘账本

先登记原 72 根中每根首个公开、合法下车状态，再计算概率和读取事后标签。每个当前候选与后续声明下车站组成一个结构对；没有该候选的后续同车登乘端点也保留。模型计算覆盖所有实际存在的两端机会，包括零概率、取消、无法到达和未知标签；目的地吸收后停止枚举。

固定完整根历史 $h$，令 $J(d_u,d_v\mid h)$ 为候选车两端发车时刻的联合律，\(\mu_b(a)\) 为乘原车到后站的到达次概率质量。后者只在实际执行的发到端点检查取消、时序和截止时刻，隐藏链槽位仅传递概率。设 \(U(d_u)\) 为上游发车可赶指示量，\(V(d_v)=1_{d_v<H,\,\mathrm{active}}\sum_{a\le d_v-\mathrm{MCT}_v}\mu_b(a)\)。原车和候选为不同车次时，

\[
p_{11}=\sum_{d_u,d_v}J(d_u,d_v\mid h)U(d_u)V(d_v),\quad
p_U=\sum J U,\quad p_V=\sum J V.
\]

其余三格为 \(p_{10}=p_U-p_{11},p_{01}=p_V-p_{11},p_{00}=1-p_U-p_V+p_{11}\)。后验转移已经含全部根证据；不重新乘消息似然，也不推进未来远端消息。候选同车两端不能用边缘概率乘积。原车和候选属于同一车次的格保留为 `probability_unresolved`，不错误套用独立性。

事后标签另行读取，取消、缺测、同车身份冲突和 MCT 分开记录。未知分区保留指示量上下界。已有 full128 银行仅重构同 seed、完整车次序号和公开历史的随机端点，用原存储双臂损失计算四分区贡献；未完损失使用原区间，贡献相加等于全银行的动作差区间。此处没有重新执行策略。

运行顺序：`python -m experiments.decision_gap_v1.event_run register`，再用 `groups` 冻结公开分组，之后运行 `evaluate`；新 full128 回执齐备后运行 `banks` 和 `usage`。预测年龄、MCT 差、原车延误和共享站间边按登记阈值报告；去重运营事件取登记顺序的首条代表，保留日期相关性及未知标签评分界。物理可赶乘、菜单可选与实际政策登乘是不同量；本账本属于已开发日期的机制诊断，不是独立概率校准或实际乘客轨迹证据。
