# decision_gap_v1：先补候选覆盖，再判断剩余决策缺口

**P1 完成，P2 的固定输入开发诊断完成；G2 未通过，当前不进入 P3–P5 或深度求解器重构。** 网页诊断的两个关键判断得到复现：root4 的独占收益来自缺失候选，root62 的收益已有便宜对照取得。本轮保留完整正、负和未知案例。

以 `a2b82be9` 为起点，固定原 72 根、V41 模型、MCT、信息时钟、128 世界/120 CPU 秒门限及原种子。统一公开规则恢复原菜单车次的上游登乘前缀，不使用事后端点或收益选候选，不增加换乘深度。72 份菜单先全部冻结，再读取覆盖标签和运行 **720 条**回放。原菜单旧观察、原菜单新观察、新菜单新观察分开计费；新域八臂共用菜单及观察。新增登乘项合计 2778 个平台上下文出现次数，平均闭包构造 CPU 0.00416 秒。

单独扩展观察，72 根动作与损失均不变。再补候选，root4 从 1721 降至 1386 秒，其余 71 根损失不变，全部平均改善 4.653 秒。新域 full128 相对 cheap **1 胜、3 负、68 平**：root62 赢 96 秒，roots6/18/32 分别损失 263/145/140 秒，平均净损失 6.278 秒。snapshot_csa 在 root62 同样达到 1399 秒。没有一根由 rollout 严格胜过全部六种固定便宜策略；逐根挑选不同策略不被当作可部署基线。

原 V51 cheap 的损失、状态、动作及公开／物理轨迹 **72/72** 一致。272 个 rollout 门全部完成原 128 对世界；122 个同状态 full 内核银行完全一致。新域独立收集 **499 状态、3020 次出现、36 个动作分歧状态**。旧 88 状态不变，遗漏的 root15/cid127/28844 独立补为第 89 个旧域诊断，未迁移证书。

P2 在读标签前登记 1918 个候选对，其中 580 个具有上游与后站同车发车端点，1338 个没有该后站端点，7 根没有两端机会。580 格完整积分全部完成，四分区实际计数为：两处均可赶 502、仅上游可赶 63、仅后站可赶 6、两处均不可赶 9。仅上游可赶的模型平均概率 **4.132%**，开发档案频率 **10.862%**；六日的频率均高于模型均值。已保存所有事件、分组、原车取消／截止／时序失败质量、实际策略登乘，以及 2320 条分区损失贡献。

**停止与下一步。** 保留新候选闭包和新 cheap 基线，停止将该覆盖机制包装为新的复杂算法。当前没有充分依据加大独立银行或完整值求解预算。若继续研究，应先按 `calibration_protocol.json` 定位未开发日期及可验证的站台换乘口径，固定验收规则后检验联合赶乘事件概率；只有剩余差距仍存在且便宜统一规则处理不好，才进入可行策略见证及结构算法阶段。P3 的 4096 世界只是原方案草案，本轮没有启动。

**限制与未完成项。** 本轮六日都是开发数据，580 个不同端点事件也共享车次，未作 iid 校准检验。35 个已接触日期全部列入排除表，独立日期尚未冻结或获取。GTFS 站级 240/420/180 秒来源已核对，当前回放没有具体到发站台，站台对尚未验证。扩展菜单 root36/39 有端点覆盖问题；本轮只有 snapshot_csa/root39 实际遇到缺测，其 [0,3600] 损失界保留于 72 根均值，不能用其余 71 根均值替代。CPU 为一次冷策略轮换测量；4 个独立根并行，wall 受竞争影响，尚非硬实时发布确认。新域结果不能证明 cheap 最优或 G2/G3 成立。
