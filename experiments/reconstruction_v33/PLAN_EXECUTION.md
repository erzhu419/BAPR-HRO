# V33：诊断计划逐项落实

依据：`md/GPT_diagnosis_v5.md` 第六至十节，以及同目录
`BAPR_HRO_GPT_diagnosis_v5/` 的 README、BOARD 审计和算法发现计划。
原包的既有负结果保留，不重跑已经完成的审计。

| 计划项 | 实际执行与证据 | 处理结论 |
|---|---|---|
| 小概率数值修复、统一两目标 | V32 的概率原子求和、`TwoTargetOpportunity` 及回归测试 | 已完成；属于维护和基线加强 |
| 双枢纽、下游独有机会、多次换乘筛查及分母 | V32 `selection.json`、`selection_full_hubs.json`、目录和数据覆盖账本 | 已完成有界自然结构发现；12 根全保留，64 枢纽、542 个续程变体 |
| 指定的 45 秒回顾空间 | V33 `witness.json`：原起点公开历史、三个下车点、完整尾值积分及 4096 个配对世界 | 已完成；标准停止与便宜滚动规则相同，45 秒不是可实现的期望收益 |
| 后验贯穿根、下车与尾站 | `history.py`、`planner.py`、`execute.py`，12 根 × 32 个原模型世界 × 6 策略 | 已完成；离站后停止收集原站未出现证据，同车跨地点只保留一个物理过程 |
| 后续车辆仍可选择下车点 | `nodes.py` 保留每辆续程车的全部既定出口，执行器到站重规划 | 已完成；未在后续登乘时锁定唯一变体 |
| 自适应续程价值接回根评分 | `joint.py`，按拓扑预选两根的全部下车点，独立 16 世界积分与 32 世界评价 | 有界积分实验；逐时刻标准误保存，不冒称完整信息树精确值 |
| 相同动作与信息的强基线 | 滚动名义、单目标、组合、两目标、rollout、标准链停止 | 已完成；主对照在 `protocol.json` 冻结，不按实际路径挑最佳规则 |
| 小规模同信息精确参照 | `reference_results.json`：两个自然共享车次切片；通用树及结构分解同时尝试 | 结构分解求得原律精确值；通用树达到预算后保留严格区间。便宜控制达到切片精确值 |
| 决策前公开消息与缺测来源 | `information_audit.json`、`followup_endpoint_audit.json`，本地档案及服务器小型 JSON 核查 | 可访问档案没有匹配日期的外部消息；恢复 3 条连接的 6 个端点，再恢复 1 个有一致源记录的发车端点，冲突到达保留 |
| 可安全遗忘的历史、同车消息复用及复杂度 | `THEORY.md`，相关车次缓存、原模型未来核复用，前缀一致性及缓存回归 | 已实现并说明充分条件；这些是标准结构工具，不宣称新的最小状态或一般网络复杂度定理 |
| 完整计算、冷启动与热缓存 | `benchmark.json` 的 24 格，总 CPU 含模型、后验、菜单与尾值准备 | 已完成小型计费对照；热缓存是同历史重放，不能外推为新旅程加速 |
| 单一新算法立项、生产规模曲线、独立日期确认 | 以强基线后仍有自然残余为启动条件 | 尚未获得立项证据；不以扩大开发样本或给标准 DP 改名替代 |

这里的“已执行”指已做具体实现或有界实验，**不等于整张网络已经精确求解，
也不等于计划的条件性算法主张已经成立**。五个缺测根、原模型不支持历史、
有限积分精度和外部消息缺口统一见 [RESULTS.md](RESULTS.md) 的限制。

下一步的必要输入是具有匹配静态图、真实端点及决策前发布消息的自然事件集。
先冻结候选规则和共同信息接口，再检验强便宜控制之后的残余；当前这批冻结根
不再追加更大的等待 DP 或采样预算。模型支持范围的修正应另立建模实验，不能
用当前评价端点反向扩大本轮冻结模型后再报告算法获益。
