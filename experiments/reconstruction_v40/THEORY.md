# V40：当前动作等价性、预算截断与方法归属

沿用 V39 的物理车次独立模型、消息选择器、完整公开历史和裁剪菜单。这里证明的是固定控制器当前查询的计算等价性；不把它升级为最优控制问题的最小充分状态。

## 两种合法的当前动作缓存

令 `F_m(M,c,h)` 为固定模型、截止、等待规则和评分方法 m 下，菜单 M、公开上下文 c、历史 h 所产生的当前动作。V39 的剩余视图删除已经经过的下车出口及 `seen\visible` 的站台根候选，只保留剩余递归菜单涉及的车次。依据 V39 的后缀递推和按车独立条件化，`F_m(M,c,h)=F_m(M_r,c_r,h|A(M_r))`。跨分支相同物理车次仍共享条件律；原始历史及每个世界的后续执行保持完整。

本轮更强的普通缓存对照 `currentmemo` 保留原菜单，但键使用该菜单相关车次的 `history.signature`。它包含有序硬观测、当前选中预测及服务状态。冻结规划器构造当前条件核和尾值时读取的正是这些量。因此，相同签名和公开上下文给出相同当前动作；无须把当前未选预测也放入这个动作的缓存键。

这不允许删除实际历史中的未选预测。后续自己的到站观测会改变已完成事件的前缀，选择器可能重新选中另一条旧预测；执行器保留全部原消息，再以更新后的签名查询。故“当前动作缓存可用较小键”和“整个演化状态必须保留未选消息”同时成立。V39 与 currentmemo 的键不互为确定投影，不能沿用 `U_frontier≤U_currentmemo`；其唯一求值数和实际成本必须实测。

固定有限世界和动作顺序时，三种实现只改变当前查询的求值及复用，不改变抽样、物理事件、条件观测、动作和损失。逐次归纳可得完整条件执行等价。本轮检验所有 148 状态的 512 世界，并以每个 bank 的前 128 世界逐项衔接原结果；在线的 128 世界锚点另检验完整实际轨迹。

## 预算下返回什么

令 `H=deadline−clock` 为当前公开决策到截止的剩余时长。对第 i 个共同世界，记两动作剩余损失为 A_i、B_i，取值在 `[0,H]`。端点不足等未解执行保持缺测，不补为成功或失败。令每个缺测值的下界为 0、上界为 H，则已完成 n 个配对的经验差均值满足

`L_n = Σ(lower(A_i)−upper(B_i))/n ≤ mean(A_i−B_i) ≤ U_n = Σ(upper(A_i)−lower(B_i))/n`。

只有 `U_n<0` 才选择替代动作，否则返回原 combined 动作。CPU 检查以完整两动作配对为原子边界；若该配对和区间更新在额度内完成，才提交动作。超时配对保存在回执中并计费，但不能更新返回值。没有及时完成配对时返回原便宜动作。因而返回的是最后一个已提交经验前缀的规则，不是截断后悄悄使用全部 512 世界的答案。

原子配对和抽样块不可中断，故这是协作式 CPU 额度，不是硬截止算法。首个决策还可能在冷启动或便宜评分时已经耗尽额度。报告实际整段决策 CPU、超限幅度、回退和最终整趟 CPU；先检查预算可行性，再解释质量比较。不同实现可在同额度内完成不同前缀并选择不同动作；因此只有固定世界数比较要求逐轨迹相同。

## 原始随机流和统计解释

每个 128 世界块按原完整路径和排序车次独立生成。块 0 沿用原种子，保持原 128 世界；后续块种子按冻结公开公式确定。保留原路径而不按剩余菜单缩减抽样，是为了不移动旧车次的随机数位置。所有生成但未使用的世界也计入抽样成本。新实际状态按根编号和当前公开事件赋种子，不读取实际续程损失或以前保存的答案。

上述缺测区间是经验 bank 的逐项界。CPU 停止可与轨迹复杂度相关，不能把固定样本标准误当成任意停止时的总体保证。512 世界增加的是条件模拟，不是独立实际事件。实际回放继续采用原逻辑交通时钟，未检验计算延迟进入物理登乘后的可执行性。
