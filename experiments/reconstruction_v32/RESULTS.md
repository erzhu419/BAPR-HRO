# V32：受限下车链探针与强基线

**本轮完成了受限首车下车链的代码、理论、目录与配对实验，共享后验仅完成局部平台核查。原诊断计划尚未全部执行。G2 未通过；暂不启动新算法立项。** 下列结果适用于当前固定尾策略与自身到达信息，不能关闭完整的信息—行动耦合方向。旧 V10–V31 及用户审计包原始回执未改。

## 完成的施工

- 修复 `FullMenuOpportunity.wait_score` 的极小生存概率消减误差。审计保存的 20 条历史与非负原子参考误差为 0；两目标互补等待例子仍成立，实际损失仍为 1428 秒。
- 新增统一 `TwoTargetOpportunity`、标准 `OnboardStopping`、滚动固定下车、一层 rollout、小菜单公共分支积分及共享车次条件更新。
- 两日各静态抽 48 辆首车，共得到 **8815 个合格首车—目的地结构**，事前选定 12 根。相同根先运行 30 枢纽截取版，再展开原八段首车范围全部 **64 枢纽、542 条尾程变体**。展开原因是三枢纽上限使一层 rollout 在单链上结构性足够；没有按损失重选根。起点能复制的最终车次与下游独有车次分别保留。

## 配对结果

各根用 512 个世界估计共同尾值，另外 512 个世界评价。每个具名车次只抽一次完整路径，跨候选和枢纽复用；所有策略只能看到公开前缀。主对照预先固定为“两目标尾控制 + 一层车内 rollout”。

| 策略 | 6144 个模型结果的平均截断损失（秒） |
|---|---:|
| 首机会尾控制 + 滚动均值下车 | 1665.199 |
| 计划优先尾控制 + 滚动均值下车 | 1608.667 |
| 单目标尾控制 + 滚动均值下车 | 1582.692 |
| 组合／两目标尾控制 + 滚动均值下车 | 1582.712 |
| 两目标尾控制 + 滚动固定下车 | 1582.822 |
| **两目标尾控制 + 一层 rollout** | **1582.788** |
| **两目标尾控制 + 标准链停止** | **1582.788** |

一层 rollout 与停止 DP 在全部 6144 个评价世界中损失逐项一致。估计 G 表内仅一根仍有 **0.017848 秒**的根差距：主要来自概率约 **0.000961**、局部差约 **18.569 秒**的合法模型历史，贡献 **0.017843 秒**。它被完整保留，不能据此宣称 rollout 普遍最优；也不足以支持一个新求解方法。独立评价中未出现这项收益。

正负案例没有只留赢家：滚动均值下车相对主对照为 **7 胜、8 负、6129 平**，平均仅好 0.0765 秒；单目标为 11 胜、13 负。复杂方法并未稳定超过这些强规则。完整逐根模型值、公共历史贡献、配对损失和计算账本见 [summary.json](summary.json) 与 [gap_catalog.json](gap_catalog.json)。

实测主对照与链停止 **5 根可配对且全部相同**：4 根到达，损失 934、894、1863、1444 秒；1 根固定首车不可用，损失 2400 秒。另 **7 根缺测**：5 根尾车发车缺测、1 根首车发车缺测、1 根已乘前缀后续发车缺测。其他策略的覆盖不同，汇总保留各自分母，没有把缺测记为旅行失败。

## 共享车次信息与计算

对全部 **18 个交叠平台**补做冻结原链的条件两目标回放：14 个首车前缀可达，10 个尾程可完整配对，均同动作、同变体、同损失；4 个尾程缺测，另 4 个前缀不可用。16 次完整公共决策中，一次 BOARD 分数下降 **6.851 秒**，仍未跨过行动边界。更新仅使用本站已观察发车及未出现区间，离站后不累积远端证据。[条件回执](conditional.json)

完整枢纽探针总工时 **156.20 秒**：模型抽样 9.22 秒，尾值编译及积分 144.30 秒，所有链控制求解合计 **0.215 秒**。条件平台探针另计 7.58 秒。这是多控制共享准备的审计工时；它已经显示首车链递推不是当前主要计算成本，没有据此声称生产算法加速。

## 决定与局限

保留数值修复、强基线、共享后验接口和目录。**当前固定尾策略的单链没有支持新方法立项；完整共享信息与后续适应方向尚未试完。** 计划后半的新状态压缩算法、冷／热性能曲线和独立新日期确认，以出现幸存机制为前提，目前暂缓。[立项决定及未完成项](decision.json)

这不是全网无算法空间的证明。数据仍是开发日期与理想发车时钟；首乘被固定，途中只观察自身到达；尾车登乘后固定其下车变体。链 DP 对输入 G 精确，G 本身为样本估计；小菜单精确表在交叠时只是固定分数代理。条件平台对照单独报告，未冒充全根条件策略积分；实测覆盖也不足以作现实普遍性结论。[理论与信息合同](THEORY.md)
