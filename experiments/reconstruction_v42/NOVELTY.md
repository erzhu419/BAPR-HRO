# V42：先例与候选结构判断

本轮固定 V41 v2 的物理模型、菜单、消息规则、基策略和 128 个配对世界。先核查理论与原始先例，再实现**事件级剩余依赖投影会合**：两条续程可以保留不同的已结束车次历史，只要剩余执行真正会读取的状态完全相同，就复用共同后缀。

**这个候选可构造、可证明，但目前属于已知上下文合并／相关信息删减的具体实现。** 是否有净计算价值应通过全部 148 状态回答；即使加速，也不能仅凭交通语义命名建立独立方法贡献。

## 与直接先例的关系

| 候选说法 | 原始先例及核查位置 | V42 能增加什么、尚缺什么 |
|---|---|---|
| 只保留未来子问题需要的历史，就能合并不同完整历史 | [Dechter–Mateescu, *AND/OR Search Spaces for Graphical Models*](https://ics.uci.edu/~dechter/publications/r126.pdf)，§5.2.2，Theorem 61（PDF 第 25–26 页）明确给出上下文合并；Theorems 65/67 给出宽度相关界 | 可以把物理车次、原始消息重选与菜单执行映射成安全上下文；尚无超出其一般原则的新合并机制或复杂度分离 |
| 从返回值／动作差值反向找依赖，只执行有关随机变量 | [Hur 等, *Slicing Probabilistic Programs*, PLDI 2014](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/slicing.pdf)，摘要及 §2–3 | 已有数据、控制及 observe 依赖的正确切片。V42 不能只删两菜单交集，或忽略未选消息以后重新起效；需要完整未来依赖闭包 |
| 不同首动作后采用共同策略，两轨迹会合后消去共同未来 | [Zahavy 等, UAI 2020](https://proceedings.mlr.press/v124/zahavy20a/zahavy20a.pdf)，§2.3、§4 | 事件级投影可能比 V41 完整入口检查更早会合；共同未来消去本身已有直接先例。该文平均奖励／遍历链保证不能直接移给本项目的有限截止模型 |
| 完整策略值可按局部随机因子消元，复杂度由宽度控制 | [Rish–Dechter, *Variable Independence in Markov Decision Problems*](https://ics.uci.edu/~csp/r42.pdf)，摘要、§5–6；[Koller–Parr, IJCAI 1999](https://ijcai.org/proceedings/1999/189)，固定策略的结构化近似评价 | 因子化转移不自动使策略值可加。若没有新的交通结构构造和更小宽度证明，改写成车次变量消元仍是已有框架的应用 |
| 已无未来决策的尾段用条件期望替代逐世界模拟 | [Murray 等, *Delayed Sampling and Automatic Rao–Blackwellization of Probabilistic Programs*, AISTATS 2018](https://proceedings.mlr.press/v84/murray18a/murray18a.pdf)，§1–2 | 解析消去可积子结构是已知方差缩减。尾段识别可便宜实现，但是否降低总误差×成本需另测；它也改变有限 bank 估计，不属于本轮逐世界严格等价对照 |

上表是逐项对应，不是“检索不到同名交通论文，所以新颖”。Koller–Parr 的近似加性策略评价也不被写成已解决本项目的精确历史策略值；Rish–Dechter 的宽度结论依赖其因子表示，不能无成本搬来。

## 本轮可检验的命题

在未来档案消息冻结、不同物理车次按 V41 独立、执行菜单有限且不引入新候选的条件下，从当前事件递归收集：尚可执行的乘车／出口、评分时读取的所有后继子树，以及这些节点对应的物理车次，得到剩余依赖集合 R。它由输入菜单和当前执行位置构造，不读取未来样本终值。

两条同一物理世界中的续程若有相同的执行位置、剩余菜单、公共时钟、就绪／已处理事件界限、当前可见与已见集合，并且 R 内每辆车的有序硬证据、所有原始预测与状态、物理基底一致，则后续观察、条件更新、动作和终值一致。对下一事件归纳即可证明：读取集合包含在 R 中；未来子菜单的集合是其子集；R 外证据不会跨独立车次改变内部后验。相同终值以后无需继续重复求解。

这比 V39 的“当前评分查询相同”命题更强，因为保留了以后可能重新选中的原始预测，并约束完整未来执行，而不是把当前 action key 当永久会合证书。它又比 V41 的严格完整历史入口比较更宽松，因为允许无后续读取的历史不同，且可以在实际事件位置检查。两处增强是本轮的正确性与实现内容；它们仍落在已有上下文相关性原则内。

下列反例决定边界：共同候选成本 x 与两臂私有后备 10、20 产生差值 min(x,10)−min(x,20)，共同变量不能直接相消；旧预测在后续自身观察后可能被重新选择；平台已见集合或就绪时刻不同会改变下一可乘车。跨世界复用仅凭相同当前历史也不成立，因为尚未揭示的物理样本不同。本轮只在同一个配对世界内复用，不将这些反例变成新模型假设。

## 立项判断

允许进行一次固定样本、全状态的等价性与完整成本实验，回答比 V41 严格入口会合多识别了多少共同后缀，检查费用是否超过节省。其结果无论正负都保留；真实回放正负案例沿用 V41，若改动了动作或损失必须先视为等价性失败。

**当前没有查明独立方法贡献。** 若仅得到上述投影会合的加速，应保留实现并按已知方法的优化报告；若没有净节省，则停止此具体计算路线。进一步的“动作差值专属依赖宽度”必须给出不会被未来策略选择重新耦合的构造及相对现有上下文方法的严格差别，不能用尚未成立的命题支撑继续扩大求解器。

独立代码审阅确认 `event_suffix.py` 与上述闭包范围一致，未发现实际正确性问题。11 项定向测试覆盖真实后缀命中、两种 V41 基策略的逐样本等价、同车过去证据、未选预测重选、站台 visit 及基底区别。原平台循环对已删除根的重复读取是幂等的，且其已发生发车不会再产生未来事件；缓存命中后直接返回终值，不会继续使用未推进的历史对象。正式全状态实验在此审核之后启动。
